AbletonDeck 0.3.15 beta for Windows

Download `AbletonDeck-Setup-0.3.15.exe` and run it. Close Stream Deck first and select your Ableton User Library (find the path in Live Settings > Library). Administrator rights, Node.js and Python are not needed by users.

After installing, restart Live when your project is saved. Put AbletonDeck Meter.amxd last on Main/Master and drag AbletonDeck actions onto Stream Deck keys. Keep yfc-meter.js next to the device. Optional Live controls require the AbletonDeck Control Surface, with Input/Output set to None.

Requirements: Windows 10/11, Stream Deck 6.6+, Ableton Live 12 Suite (tested configuration). One meter per project. macOS is not supported by this installer.

Spectrum, one-key spectrogram, oscilloscope, goniometer, Mid/Side balance, LUFS, sample peak, frequency-to-note detection and reactive particles. Numerical integrated LUFS is experimental; sample peak is not true peak.

The installer is currently unsigned. The source and build scripts are included in this repository. SHA256SUMS.txt identifies the released installer. To remove files, run the same installer, select the same User Library and click Remove. Modified files and user profiles are preserved.
